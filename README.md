# 🏛️ DOMI / AURA - Plateforme Hybride Immobilier & Art

> **Le futur de l'habitat et de la culture numérique à Yaoundé.**

**DOMI / AURA** est un écosystème numérique innovant conçu pour répondre à deux défis majeurs au Cameroun : la recherche simplifiée de logements (DOMI) et la valorisation des talents artistiques numériques (AURA).

---

## 🌟 Vision du Projet

Le projet repose sur une dualité unique :
* **DOMI (Le Domicile) :** Une solution de recherche immobilière intuitive pour les étudiants et jeunes professionnels de Yaoundé (ENSPY, etc.).
* **AURA (L'Art) :** Une galerie immersive pour exposer et monétiser les créations numériques (NFTs, Modélisations 3D, Design).

## 🚀 Fonctionnalités Actuelles (MVP)

- [x] **Moteur de recherche dynamique** : Recherche en temps réel par mots-clés (Bastos, Akwa, Luxe, etc.).
- [x] **Système de filtrage** : Boutons de tri par catégorie (Immobilier vs Art).
- [x] **Design Responsive** : Interface fluide adaptée aux smartphones et ordinateurs.
- [x] **Déploiement Continu** : Site hébergé via GitHub Pages.

## 🛠️ Technologies Utilisées

- **Frontend** : HTML5, CSS3 (Grid & Flexbox).
- **Logique** : JavaScript ES6+ (Manipulation dynamique du DOM).
- **Versionnage** : Git & GitHub pour le suivi du développement.

## 📈 Prochaines Étapes

1.  **Intégration d'une base de données réelle** : Passage de fichiers JSON locaux à une base de données cloud.
2.  **Visites 3D** : Intégration de modules de visualisation immersive pour les logements.
3.  **Espace Artiste** : Formulaire permettant aux créateurs de soumettre leurs œuvres.

## ⚙️ Installation Locale

Pour tester le projet sur votre machine :

1.  Cloner le dépôt :
    ```bash
    git clone [https://github.com/Olivieraustinmani-PNG/domi-project.git](https://github.com/Olivieraustinmani-PNG/domi-project.git)
    ```
2.  Ouvrir le dossier :
    ```bash
    cd domi-project
    ```
3.  Lancer `index.html` dans votre navigateur.
